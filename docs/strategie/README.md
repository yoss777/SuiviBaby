# Stratégie SuiviBaby (novembre 2026)

Travail produit avec les skills founder (board, competitors, offer, pricing, consumer, cfo, brand, marketing, launch, ops, plan) et une revue UI/UX outillée. Le panel d'acheteurs est **simulé** et les chiffres sont des **projections** : seuls de vrais clients, le sondage de prix et de vrais devis les confirmeront. Ce n'est ni un conseil financier, ni un conseil juridique ou fiscal.
